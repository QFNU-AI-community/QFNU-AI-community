# 知创未来 AI 社 · QFNU AI Community
> 来自曲阜师范大学的学生 AI 社区，致力于在校园内构建高质量开源生态。
## 我们是谁
我们是**曲阜师范大学的学生 AI 社区**，一个以项目为驱动的校级社团，各专业同学在这里打造真实的 AI 产品。随着 AI 与 vibe coding 大幅降低软件开发门槛，我们让每一位同学都能把创意变成可运行的应用。
## 这里有什么
本组织账号是**社团成员作品的集中地**——一个由学生 AI 项目构成的精选作品集，涵盖大模型应用、智能体与 RAG 系统、AI 工具与全栈应用、竞赛与黑客松项目，以及公开的学习资源。校园里的优秀作品在此统一维护、展示，以便触达全球开发者。
## 我们的目标
打造**大学高质量开源社区**——发掘并推广优秀学生项目，推动开源协作，帮助有潜力的项目从原型成长为真正的产品，并有机会走向商业化。
## 与我们协作
- **开发者**：欢迎浏览项目、提交 Issue 与贡献代码，与全球开源社区共同协作；
- **企业 / 机构**：欢迎在项目合作、人才对接、成果落地等方面与我们联系。
